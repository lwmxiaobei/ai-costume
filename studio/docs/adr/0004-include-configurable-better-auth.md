# ADR 0004：加入按配置启用的 Better Auth

## 状态

已接受

## 背景

来源项目已经验证了 Better Auth、Google OAuth、Hono、Cloudflare Worker 和 D1 的完整组合。新项目重复建立认证表、回调路由和会话组件会产生稳定的重复成本。

## 决策

模板默认安装 Better Auth 并提供 Google 登录组件、D1 核心表、认证路由和会话接口。只有完整配置基础 URL、足够长度的秘密和两项 Google OAuth 凭据时，界面才开放登录。

## 后果

优点是需要账户的新项目可以直接启用登录，不需要账户的项目在未配置时不会暴露失效入口。

缺点是 Worker 需要 nodejs_compat，模板增加认证依赖和四张 D1 表。具体资源授权仍需项目自行实现。

## 备选方案

继续仅提供文档会让每个项目重复实现认证基础设施，因此不采用。

强制所有写接口登录会错误改变匿名产品的业务模型，因此不采用。
