# ADR 0003：认证不进入默认内核

## 状态

已被 ADR 0004 取代

## 背景

一个来源项目使用 Better Auth 与 Google OAuth，另一个来源项目的核心购买链路不依赖账户。认证不是两者的稳定交集。

## 决策

原决策是默认模板不安装认证依赖。用户随后确认 Better Auth 登录也属于需要复用的基础能力，因此由 ADR 0004 取代。

## 后果

优点是匿名产品、公开目录和带账户产品都能从同一模板开始。

缺点是默认项目的写接口不能直接用于公开生产环境，必须增加认证、验证码或速率限制。

## 备选方案

默认集成 Better Auth 会给无需账户的项目增加迁移、秘密和用户数据责任，因此不采用。
