# ADR 0001：保留单体 Cloudflare 全栈

## 状态

已接受

## 背景

两个来源项目都使用 React、Vite、Hono Worker、Static Assets 和 D1。当前规模不需要拆分多个服务。

## 决策

模板保留一个 Worker、一个前端构建和一个 D1 数据库。

## 后果

优点是部署简单、同域请求无需额外 CORS、开发和运维成本低。

缺点是 Worker 代码需要主动拆模块，数据库和 API 的扩展受 D1 与 Workers 运行时约束。

## 备选方案

独立前端托管和 Node API 会增加部署、跨域和秘密管理成本，因此暂不采用。

微服务会扩大当前产品规模不需要的运维面，因此暂不采用。
