# 多语言设计

支持简体中文、繁体中文、英语和日语，使用页头下拉框切换。首次访问按浏览器语言选择，手动选择保存在本地。切换时保留分类、搜索条件和已加载数量。

界面词典位于 `src/i18n.js`，网站内容翻译位于 `site.config.json` 的 `locales`。构建时将网站配置内嵌到页面，图片数据加载失败时仍能显示所选语言的说明和错误提示。页面标题、描述与无障碍标签同步切换。

服装说明使用 `scripts/keyword-translations.json` 中的短语与颜色词典，由构建脚本生成三种译文。图库的分类键和图片地址保持稳定，搜索同时匹配原文、译文及常用搜索词。自定义导入内容没有对应译文时显示原文。

各语言说明图片采用 CC BY-ND 4.0，允许商用及署名转载，不得分享或公开发布改编版本，并提供作者和许可链接。语言选择存储不可用时仍可浏览并切换语言。

验证包括语言优先级、中文地区及文字变体、服装说明组合翻译、现有图片接口回归，以及桌面和手机的语言切换、搜索、下载、错误状态和布局检查。
